Quick Reference

HasTask

"Does the conversation contain an unresolved request or action?"

Yes → TRUE   No → FALSE

IsImportant

"Is this conversation urgent or high organizational impact?"

Yes → TRUE   No → FALSE

HasTask = TRUE

  • Someone is asked to do, send, review, approve
  • A question expecting an answer
  • Follow-up on a prior unresolved ask
  • Request for sign-off, availability, decision

HasTask = FALSE

  • FYI, status update, announcement
  • Sender's own commitment ("I'll do it")
  • All asks resolved in thread
  • Social, greeting, bot-generated

Task Type (when TRUE)

  • RfA: Action, Review, Schedule, Delegate
  • RfK: Question, Confirm, RSVP, Status, Decision
  • Follow-up: Re-surfaces prior ask

Attribution (when TRUE)

  • Explicit: @mention or named assignee
  • Implicit: Name in text / 1:1 context
  • Unassigned: "Can someone…" / broadcast
